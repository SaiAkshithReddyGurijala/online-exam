# Online Examination System - Software Engineering Lab Internal

This repository is the starter project for the Software Engineering Lab Internal Examination.

## Application
A small Maven-based Java Web Application for an Online Examination System.

The starter repository intentionally contains issues in `pom.xml`. Students are expected to inspect, diagnose and correct the build configuration before implementing their assigned feature.

## Initial functionality
- Home page
- Student login simulation
- Examination list
- Basic examination page
- Faculty Question Bank page (starter placeholder)

## Build
After correcting `pom.xml`, use Maven lifecycle phases to compile, test and package the application.

## Docker
The final application should be containerized using a Java/Tomcat runtime image. See the examination instructions for the exact task.

## Important
Do not add credentials, API keys, passwords or personal tokens to this repository.
